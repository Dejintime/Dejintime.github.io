# 1. BERT模型架构
BERT全称为 *Bidirectional Encoder Representation from Transformer*
## 1.1 整体架构概览
<img class="img-medium" src="{{ '/assets/images/bert-architecture-overview.png' | relative_url }}" alt="BERT 预训练与微调架构概览" />
+ **Pre-training**展示了Bert的预训练模型架构，其中包括了MLM(Masked Language Model)和NSP(Next Sentence Prediction)两个核心任务，使用无标注的数据进行预训练，帮助模型学习语义特征，输出丰富的语义向量。
+ **Fine-Tuning**展示了Bert的微调模型架构，使用了迁移学习的思想，将预训练模型的参数照搬过来，针对不同的下游任务使用带有标签的数据进行训练微调。

## 1.2 输入表示（Input Embedding）
<img class="img-medium" src="{{ '/assets/images/bert-input-embedding.png' | relative_url }}" alt="BERT 输入表示（Input Embedding）" />
三个嵌入向量的维度相同，对应维度两两相加得到 $Input$ 的初始词向量
### Token Embedding

使用 **WordPiece** 分词技术将单词切分为子词（subword），再将每个子词映射为一个固定维度的向量。

  **WordPiece 分词的特点**：
  - **子词粒度**：将低频词拆分为更小的子词单元（如 `playing` → `play` + `##ing`），高频词保持完整，有效缓解 OOV（Out-of-Vocabulary）问题
  - **贪婪最长匹配**：分词时从前往后匹配词表中存在的最长子词，最大化每个片段的长度
  - **共享词根**：利用前缀 `##` 标记非首字子词，相同词根的变体如 `run` / `running` / `runs` 共享部分子词，既压缩词表大小又保留形态学信息
  - **词表构建**：基于语料统计，以最大化语言模型似然为目标，通过 BPE 类似的合并策略迭代构建词表

  **特殊标记**：BERT 的词表还包含几个关键的特殊 token：
  - `[CLS]`：分类标记，置于每个输入序列的首位，其最终输出向量作为整句的聚合表征用于分类任务
  - `[SEP]`：分隔标记，用于区分两个句子或标记序列结束
  - `[MASK]`：掩码标记，预训练时用于遮掩需要预测的词
  - `[PAD]`：填充标记，将不等长序列补零到统一长度
  - `[UNK]`：未知词标记，处理词表外的字符
###  Segment Embedding

句段嵌入层，用于区分输入序列中不同句子的归属。每个 token 附带一个可学习的句段 ID 向量（A 句为 0，B 句为 1），模型通过该信号感知句子边界，这对于 NSP 等需要理解句间关系的任务至关重要。
### Position Embedding

BERT 使用**可学习的位置嵌入（Learned Positional Embedding）**，而非 Transformer 论文中的正弦/余弦固定编码。每个位置 $[0, 1, \dots, 511]$ 对应一个独立的可训练向量，在预训练过程中随模型一起优化。

  **与正弦位置编码的对比**：
  - 可学习式：更灵活，模型自行发现适合语料的位置表示模式；缺点是无法外推到超过训练长度的序列
  - 正弦式（Transformer 原始方案）：有明确数学形式 $PE(pos, 2i) = \sin(pos / 10000^{2i/d})$，理论上支持任意长度外推，但表达能力受限于固定函数形式

## 1.3 BERT 的两种规格
- BERT-Base（L=12, H=768, A=12, 110M 参数）
- BERT-Large（L=24, H=1024, A=16, 340M 参数）
其中 $L$ 表示transformer Encoder层的数量， $H$ 表示特征向量的维数，隐藏层的维数为 $4H$，$A$ 表示Self-Attention的头数。

# 2. BERT 的训练方法机制

## 2.1 预训练任务一：Masked Language Model（MLM）

MLM 是 BERT 预训练的核心任务，其目标是在输入序列中随机遮盖部分 token，让模型根据**双向上下文**预测被遮盖位置的原词。
### 设计动机
BERT 希望同时利用左右两侧的上下文提取上下文语义信息，但如果直接双向暴露所有词，"预测下一个词"的任务就退化为"抄答案"——模型可以直接看到目标词本身。MLM 通过主动 Mask 目标词，切断了这个短路路径：模型仍能双向看到上下文，但被遮住的词必须靠上下文推断，于是目标函数就变为了：$$  P(w_i|w_1,...,w_{i−1},w_{i+1},⋯,w_n)$$
### 2.1.1 Mask 策略：80-10-10 规则
- 80% 替换为 `[MASK]`
- 10% 替换为随机词
- 10% 保持不变（但仍需预测）

**举例** — 假设原始输入为：

> `the man went to the store and bought a gallon of milk`

选中 15% token 用于预测（这里选中的是 `went`、`store`、`gallon`），对每个选中词按 80-10-10 概率分配，一种可能的处理结果为：

| 原词 | 替换为 | 原因 |
|------|--------|------|
| `went` | `[MASK]` | 落入 80% 区间，用掩码替代 |
| `store` | `apple` | 落入 10% 区间，用随机词替代 |
| `gallon` | `gallon`（不变）| 落入 10% 区间，保持原词 |

最终输入序列变为：

> `the man [MASK] to the apple and bought a gallon of milk`

模型在三个位置分别需要预测 `went`、`store`、`gallon`。注意未被选中的 85% token 作为双向上下文保持不变，模型可以自由利用它们的信息。

### 2.1.2 为何不全用 `[MASK]`--> 缓解预训练与微调的不匹配

核心问题：`[MASK]` 只在预训练中出现，微调阶段的下游任务输入中**没有 `[MASK]`**。如果预训练时所有被选中的词都变成 `[MASK]`，模型会学到一个投机策略——"看到 `[MASK]` 才需要预测，没看到就不用费心"——这种依赖在微调时完全失效。

作者在论文中提到这样做的好处是，编码器不知道哪些词需要预测的，哪些词是错误的，因此**被迫需要学习每一个 token 的表示向量**，三种情况共同训练，使模型在微调时面对没有 `[MASK]` 的普通输入文本也能正常产出高质量的表征向量。

## 2.2 预训练任务二：Next Sentence Prediction（NSP）

单纯靠 MLM 只能学到**词级别**的语义，但很多下游任务（如问答、自然语言推理、段落检索）需要理解**句子间的关系**。NSP 的设计定位就是补充这一能力：让模型判断两个句子在原文中是否连续。

**具体做法**：构造输入时，50% 的概率使用真实的连续句对（正样本），50% 的概率使用随机拼接的句对（负样本）。模型仅通过 `[CLS]` 位置的最终输出向量做二分类：**预测 B 句是否是 A 句的下一句**。

### 正负样本构造示例

假设从语料中取出两篇文档片段：

> **文档 1**：`[CLS] my dog is cute [SEP] he likes playing ball [SEP]`
> — 其中 "my dog is cute"（A 句）和 "he likes playing ball"（B 句）是原文中的连续句对，构成 **IsNext（正样本）**。

> **文档 2**：`[CLS] the sky is blue [SEP] I went to the store [SEP]`
> — 其中 "the sky is blue"（A 句）和 "I went to the store"（B 句）来自不同文档，毫无语义关联，构成 **NotNext（负样本）**。

模型对每个输入输出一个二分类结果，与标签（IsNext / NotNext）计算交叉熵损失。这些训练样本从原始语料中自动生成，无需人工标注。

### `[CLS]` 与 Segment Embedding 的角色

- **`[CLS]`**：其最终输出向量经过一个线性层后直接输出二分类概率，是整句关系的聚合表征位
- **Segment Embedding**：A 句所有 token 的 Segment ID = 0，B 句 = 1，模型借此区分两个句子的边界（详见 [[#1.2 输入表示（Input Embedding）]]）
- **`[SEP]`**：作为 A 句和 B 句之间的分隔符，同时在句对末尾也加一个 `[SEP]`

## 2.4 Fine-Tuning 微调机制

Bert微调模型使用的数据是标注的数据，其模型权重初始化为预训练的模型权重，因此Bert在下游任务中模型架构与预训练阶段几乎一致。Bert常见的下游任务有句对分类、单句分类、文本问答、单句标注。
## 句对分类
<img class="img-small" src="{{ '/assets/images/bert-classification-task.png' | relative_url }}" alt="句对分类任务示意图" />
输入格式为 `[CLS]` + A 句 + `[SEP]` + B 句 + `[SEP]`，Segment ID 分别设为 0 和 1 以区分两句话。取 `[CLS]` 位置的最终隐向量 $C \in \mathbb{R}^H$ 接一个线性层映射到 $K$ 维（$K$ 为类别数），经 Softmax 得到类别概率分布，概率最大对应的类别为预测标签，最后与真实标签计算交叉熵损失后反向传播更新全部参数。

>任务：判断句子 "我很喜欢你" 和句子 "我很中意你" 是否相似
>输入改写：`[CLS]` 我很喜欢你 `[SEP]` 我很中意你 `[SEP]`
>取 `[CLS]` 标签对应输出：[0.02, 0.98]
>通过 argmax 操作得到相似类别为 1（类别索引从 0 开始），即两个句子相似。

## 单句分类
<img class="img-small" src="{{ '/assets/images/bert-classification-task.png' | relative_url }}" alt="单句分类任务示意图" />
输入格式为 `[CLS]` + 待分类文本 + `[SEP]`，Segment ID 统一为 0。与句对分类类似，取 `[CLS]` 位置的隐向量 $C$ 接线性层 + Softmax 做 $K$ 分类(2分类$K=2$)，交叉熵损失优化全部参数。

>任务：判断句子 "这家餐厅的菜品精致，服务也很周到" 的情感极性
>输入改写：`[CLS]` 这家餐厅的菜品精致，服务也很周到 `[SEP]`
>取 `[CLS]` 标签对应输出：[0.03, 0.97]
>通过 argmax 操作得到情感类别为 1（0 为负向，1 为正向），即该评论为正面评价。

## 文本问答
<img class="img-small" src="{{ '/assets/images/bert-qa-task.png' | relative_url }}" alt="文本问答任务示意图" />
输入格式为 `[CLS]` + 问题 + `[SEP]` + 文章段落 + `[SEP]`，Segment ID 分别设为 0 和 1。模型在顶层引入两个可训练向量 $S$（起点）和 $E$（终点），对文章部分每个 token 的隐向量 $T_i$ 计算与 $S$ 和 $E$ 的点积分数，分别经 Softmax 归一化得到该位置是答案起始和结束位置的概率。损失为起止位置交叉熵之和，反向传播更新全部参数。

>任务：根据文章回答 "北京奥运会是哪一年举办的"
>输入改写：`[CLS]` 北京奥运会是哪一年举办的 `[SEP]` 北京于 2008 年举办了第 29 届夏季奥林匹克运动会 `[SEP]`
>起点向量 $S$ 对文章各 token 的打分经 Softmax 后在 "2008" 位置取得最大概率，终点向量 $E$ 同样在 "2008" 位置取得最大概率，此抽取答案 "2008"。

## 单句标注
<img class="img-small" src="{{ '/assets/images/bert-ner-task.png' | relative_url }}" alt="单句标注（NER）任务示意图" />
给定一个句子，标注每个词的标签，称为单句标注。例如标注句子中的人名、地名和机构名。单句标注与 BERT 预训练任务差异较大，但与文本问答类似：不需要引入辅助向量，取每个 token 位置的最终隐向量 $T_i$，各自接一个**共享参数**的线性层，将语义特征转化为标注任务所需的特征后做 Softmax，即可得到各类标签的概率分布。对每个 token 独立计算交叉熵损失（忽略 `[PAD]` 位置）、求和平均后反向传播优化。

由于 BERT 的 WordPiece 分词会将独立词拆成若干子词，序列标注通常使用 **IOBES** 标记法，以完整还原实体边界。IOBES 将标签分为 5 大类，结合实体类型（人名 PER、地名 LOC、机构名 ORG）细分为若干小类：

- **S**（Single）：独立实体词，如 "柏林" 单独构成地名 → S-LOC
- **B**（Begin）：多词实体的起始词，如 "爱" 是 "爱因斯坦" 的首字 → B-PER
- **I**（Intermediate）：多词实体的中间词，如 "因" → I-PER
- **E**（End）：多词实体的结束词，如 "斯坦" → E-PER
- **O**（Other）：非实体词，如普通动词、介词等

>任务：给定句子 "爱因斯坦在柏林发表演讲"，根据 IOBES 标注 NER 结果
>输入改写：`[CLS]` 爱 因 斯坦 在 柏林 发表 演讲 `[SEP]`
>BERT 对每个 token 输出各类别的概率（经 Softmax），以下为简化表示：

| IOBES | 爱        | 因        | 斯坦       | 在    | 柏林       | 发表   | 演讲   |
| ----- | -------- | -------- | -------- | ---- | -------- | ---- | ---- |
| O     | 0.01     | 0.01     | 0.01     | 0.90 | 0.01     | 0.90 | 0.90 |
| B-PER | **0.90** | 0.01     | 0.01     | 0.01 | 0.01     | 0.01 | 0.01 |
| I-PER | 0.01     | **0.90** | 0.01     | 0.01 | 0.01     | 0.01 | 0.01 |
| E-PER | 0.01     | 0.01     | **0.90** | 0.01 | 0.01     | 0.01 | 0.01 |
| S-LOC | 0.01     | 0.01     | 0.01     | 0.01 | **0.90** | 0.01 | 0.01 |

>对每个 token 的 Softmax 结果取 argmax（上表加粗项），得到最终标注：**"爱因斯坦" 为人名（B-PER + I-PER + E-PER），"柏林" 为地名（S-LOC），其余为 O**。

# 3. BERT 的核心特点

## 深度双向上下文建模

不同于 GPT 的单向自回归语言模型（只能从左到右）或 ELMo 的浅层双向拼接（分别训练前向和后向 LSTM 再拼接，两个方向的表征在每层内部并未真正交互），BERT 在每一层 Transformer Encoder 中通过 Self-Attention 让每个 token 同时对所有位置的无遮挡双向上下文做交互计算，实现真正意义上的深层语义融合。

## 统一的预训练-微调范式

不管下游是情感分类、语义相似度、命名实体识别还是阅读理解，BERT 都使用完全相同的 Encoder 主架构，仅在顶层接一个轻量任
务专用输出层，所有参数端到端联合微调，无需针对不同任务重新设计模型骨架。

## 从大规模无标注语料中学习通用语言表征

BERT 在 BooksCorpus（8 亿词）和英文 Wikipedia（25 亿词）上进行预训练，通过 MLM 和 NSP 两个自监督任务从海量文本中蒸馏出词法、句法、语义乃至百科常识，使下游任务即便标注数据极少也能获得高质量的初始化。

## 上下文相关的动态词向量

同一个词在不同句子中不再被映射为同一个静态向量（像 Word2Vec 或 GloVe 那样），而是根据当前句子的整体语境动态生成。这从根本上解决了传统静态词向量的词义歧义问题——一个多义词的所有语义被压在同一个向量里，用的时候无法分离。
